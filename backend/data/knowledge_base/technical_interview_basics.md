# Technical Interview Basics & Coding Rounds

Technical assessments evaluate problem-solving clarity and system intuition:
- **Coding Screen (DSA)**: Focus on arrays, hash maps, two pointers, sliding windows, tree traversals, and graphs. Time and space complexity analysis (Big-O) is mandatory.
- **Communicate Thought Process**: Think out loud. Clarify edge cases (e.g., null inputs, negative values, empty arrays) before typing any code.
- **Start with Brute Force**: Articulate a brute-force approach first to confirm understanding, then optimize systematically.
- **Write Modular Code**: Use clean variable names and helper functions. Write dry-run tests with example test cases to catch off-by-one errors.
