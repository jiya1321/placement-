# Action-Oriented Resume Crafting Tips

When engineering a technical resume, prioritize impact over passive duty descriptions:
- **XYZ Formula**: Structure bullet points following Google's recommendation: "Accomplished [X] as measured by [Y], by doing [Z]".
- **Strong Action Verbs**: Use dynamic verbs like *Architected, Engineered, Spearheaded, Refactored, Optimized, Deployed, Benchmarked* rather than "Helped with" or "Worked on".
- **Quantification**: State concrete metrics wherever possible (e.g., "reduced latency by 34%", "supported 1,200 active weekly users", "improved test coverage from 60% to 88%").
- **Skills Categorization**: Group your technical competencies logically into Languages (e.g., Python, TypeScript), Frameworks (e.g., React, FastAPI), Databases (e.g., PostgreSQL, SQLite), and Developer Tools (e.g., Docker, Git).
- **Format**: Keep student resumes strictly to one single page, standard margins (0.5 to 0.75 in), clean hierarchy, and ATS-friendly plain text or single-column layout.
